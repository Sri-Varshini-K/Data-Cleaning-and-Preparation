# Excel Assignment 2 – Data Cleaning 

## Project Overview
Performed data cleaning and preparation using Microsoft Excel to improve data quality and consistency for analysis.

## Tasks Performed
- Identified and handled missing values.
- Standardized product names and corrected category types.
- Identified and removed duplicate records.
- Split Product ID into Manufacturing Date and Country Code.
- Merged Brand Name and Product Name into Product Brand.
- Applied currency and date formatting.
- Used conditional formatting to highlight prices and Electronics products.

- Microsoft Excel

- Duplicate Removal
- Data Transformation
- Conditional Formatting
- Data Preparation

Gained practical experience in cleaning, organizing, and formatting datasets using Excel to prepare data for further analysis.
